# HS Eletrônicos

Projeto da marca e MVP PWA da HS Eletrônicos, responsável Hugo, com atuação em Belo Horizonte e região e atendimento presencial e reparação 24 horas.

## Aplicativo

O projeto Next.js está em [`03_Site/pwa`](03_Site/pwa/README.md). Para rodar:

```sh
cd 03_Site/pwa
npm ci
npm run build
npm start
```

Prévia: http://127.0.0.1:3000. Leia o README do aplicativo para testes, instalação PWA e publicação na Vercel. Ao importar na Vercel, selecione `03_Site/pwa` como Root Directory.
